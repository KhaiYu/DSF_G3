Git 团队协作操作指南 (V3版)

=========================================
一、 前期准备 (仅需做一次)
=========================================
1. 安装 Git
   - 前往 https://git-scm.com/ 下载并安装。
   - 安装时一路点击 "Next" 即可。

2. 身份配置
   打开 CMD（命令提示符），输入以下命令并回车：
   - git config --global user.name "你的GitHub用户名"
   - git config --global user.email "你的GitHub邮箱"

3. 获取项目 (下载到本地)
   找一个文件夹（建议不要放在 OneDrive 路径下！），在 CMD 中输入：
   - git clone https://github.com/KhaiYu/DSF_G3.git

=========================================
二、 日常开发流程 (每次开工/完工必做)
=========================================

Step 1: 开工前先更新 (Pull)
- 每天写代码前，先拿最新版本：
- 命令：git pull origin main
- 注意：如果 Jupyter 已经开着，请在页面点击 File -> Reload Notebook from Disk。

Step 3: 保存并打包 (Add & Commit) 完工过后
这里有两种选法，请根据情况操作：
- 选项 A：只上传一个特定文件 (推荐，防止乱传杂物)
  命令：git add 文件名.ipynb
- 选项 B：上传全部改动
  命令：git add .
- 最后提交备注：
  命令：git commit -m "备注你今天改了什么"

Step 4: 推送到 GitHub (Push)
- 把代码发给组长/队员：
- 命令：git push origin main
- 提示：如果报错被拒绝，请先执行 Step 1 再试。

=========================================
三、 常见问题处理 (救急手册)
=========================================

1. 如何查看之前的版本编号 (哈希值)？
- 想看谁提交过什么，或者准备回退时使用：
- 命令：git log --oneline
- 结果示例：a1b2c3d 更新了模型 (开头的 a1b2c3d 就是编号)

2. 想要撤销操作 (回到某个编号)
- 找到编号（如 e5f6g7h）后输入：
- 命令：git reset --hard e5f6g7h
- 注意：这会彻底覆盖你现在的本地文件，操作前请确认！

3. 报错：rejected (被拒绝)
- 原因：GitHub 上有别人的更新。
- 解决：先跑一遍 git pull origin main，然后再 git push。

4. 报错：NotJSONError (Notebook 打不开)
- 原因：文件冲突或 OneDrive 同步导致损坏。
- 解决：运行 git checkout main -- 文件名.ipynb (用云端版覆盖本地)。

=========================================
四、 团队守则 (必读)
=========================================
1. 严禁在未告知组长的情况下使用 git push --force。
2. 每个人尽量负责不同的 .ipynb 文件，避免冲突。
3. 输入文件名时，按 Tab 键可以自动补全，防止打错字。
4. 路径尽量避开 OneDrive 同步文件夹，防止文件被锁死。
